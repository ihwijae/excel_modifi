# 작업 인계 문서 (2025-10-16)

이 문서는 엑셀 업데이터 프로그램에 대해 현재까지 진행된 주요 버그 수정, 기능 개선, 시스템 분석 내역을 다음 세션 또는 다른 담당자에게 인계하기 위해 작성되었습니다.

---

## 1. 핵심 로직 및 버그 수정

### 1.1. 신규 데이터 추가 시 덮어쓰기 버그
- **문제점**: 엑셀 시트의 특정 구간(예: 50~65행) 내부에 빈 열이 있을 경우, 신규 데이터를 해당 빈 열에 추가하지 않고 다음 구간(예: 66행)의 데이터를 덮어쓰는 치명적인 버그.
- **원인**: `ocr_logic.py`의 `add_new_company_data` 함수에서, 현재 구간의 라벨 위치를 스캔하는 반복문이 구간의 끝 행(`sec_end`)보다 1만큼 더 진행(`sec_end + 2`)하여 다음 구간의 라벨 정보를 잘못 가져왔기 때문.
- **조치 사항**: 반복문 범위를 `sec_end + 1`로 수정하여 현재 작업 구간을 벗어나지 않도록 수정 완료.

### 1.2. 새 구간 생성 시 서식 미적용 문제
- **문제점**: 모든 열이 가득 차 새로운 구간을 생성할 때, 데이터가 들어갈 B~M열이 서식이 없는 흰색 빈칸으로 생성됨.
- **원인**: 새 구간 생성 로직이 A열(라벨)의 서식만 복사하고 B~M열의 서식은 복사하지 않았음.
- **조치 사항**: `ocr_logic.py`의 `add_new_company_data` 함수를 수정. 새 구간 생성 시, 마지막 구간의 서식을 복사하되, B~M열은 **채우기 색상을 제외한** 모든 서식(테두리, 글꼴 등)만 복사하도록 수정하여 데이터 상태와 무관한 깨끗한 슬롯이 생성되도록 개선.

### 1.3. `config.py` 설정 오류로 인한 데이터 누락
- **문제점**: 기존 업체를 조회할 때 '상호'와 '영업기간' 데이터를 가져오지 못하는 문제.
- **원인**: `ocr_logic.py`의 `find_company_data` 함수는 `COLUMN_MAP`의 값(예: '회사명')을 키로 사용하여 `RELATIVE_OFFSETS`에서 위치 정보를 찾음. 하지만 `RELATIVE_OFFSETS`에는 '회사명'이 아닌 '상호'로 키가 잘못 설정되어 있어 키-값 불일치 발생.
- **조치 사항**: `config.py`의 `RELATIVE_OFFSETS` 딕셔너리 키를 `COLUMN_MAP`의 값과 일치하도록 수정 (`'상호' -> '회사명'` 등)하여 해결.

## 2. 기능 추가 및 개선

### 2.1. '자료 파일 없이 저장' 모드에서 신규 업체 추가
- **문제점**: 해당 모드에서는 기존 업체 '수정'만 가능하고, 신규 업체 추가 시 "사업자번호를 찾을 수 없다" 오류 발생.
- **조치 사항**: `business_status_tab.py`의 `save_data_to_excel` 함수 로직을 수정. 해당 모드에서도 신규 업체 여부를 먼저 판단하여, 신규 업체일 경우 추가 로직(`add_new_company_data`)이 호출되도록 개선.

### 2.2. 사업자등록번호 입력 필드 자동 하이픈 추가
- **요청 사항**: 사용자가 `1112233333`과 같이 숫자만 입력해도 `111-22-33333` 형식으로 자동 변환되는 기능.
- **조치 사항**: `business_status_tab.py`에 `format_biz_no_input` 함수를 새로 추가하고, '사업자등록번호' 입력 필드의 `textChanged` 시그널에 연결하여 실시간으로 텍스트 형식이 변환되도록 구현.

## 3. UI 및 빌드 문제 해결

### 3.1. 폰트 적용 후 레이아웃 깨짐 현상
- **문제점**: 커스텀 폰트(Pretendard) 적용 후, 이미지를 불러오거나 확대/축소 시 창의 세로 크기가 비정상적으로 변하며 하단 버튼이 잘리는 문제. 폰트를 비활성화하면 문제가 발생하지 않음을 확인.
- **원인**: 커스텀 폰트의 크기 정보(Font Metrics)로 인해 우측 컨트롤 패널의 전체적인 최소 요구 높이가 증가함. 이로 인해 레이아웃 재계산 시 공간이 부족해져 UI가 깨짐.
- **조치 사항**: `business_status_tab.py`의 `setup_ui` 함수를 수정. 기존에 고정되어 있던 우측 `controls_panel`을 `QScrollArea` 위젯으로 감싸서, 패널의 내용이 길어질 경우 자체 스크롤바가 생기도록 수정. 이를 통해 컨트롤 패널이 전체 레이아웃에 영향을 주지 않도록 원천적으로 해결.

### 3.2. PyInstaller 빌드 시 폰트 미포함 문제
- **문제점**: PyInstaller로 빌드한 실행 파일(.exe)에서 커스텀 폰트가 적용되지 않음.
- **원인**: PyInstaller가 폰트와 같은 데이터 파일을 자동으로 빌드에 포함하지 않기 때문.
- **조치 사항**:
  1.  `main.spec` 파일의 `datas` 리스트에 `('fonts', 'fonts')`를 추가하여 폰트 폴더를 빌드에 포함하도록 설정.
  2.  `main.py`에 `resource_path` 함수를 추가하고, `os.path.dirname(__file__)`을 사용하도록 수정하여 개발 환경과 빌드 환경 모두에서 폰트 파일의 절대 경로를 정확히 찾도록 수정.

### 3.3. 전역 폰트 크기 조정
- **요청 사항**: 폰트 적용 후 UI가 전반적으로 커져 스크롤이 많아졌으니, 기본 크기를 줄여달라는 요청.
- **조치 사항**: `main.py`에서 전역 폰트를 설정하는 `app.setFont` 부분에 크기를 9pt로 명시 (`QFont(font_family, 9)`)하여 해결. (사용자 요청에 따라 미리보기 테이블의 폰트 크기는 유지함)
